# Инструкция
В папке scripts написаны .sh-скрипты для развертывания кластера Hadoop.
В скриптах реализованы следующие этапы развертки:
- prepare.sh: с помощью авторизации по ssh-ключу пользователя team на edge-ноде проходимся по всем нодам, делаем sudo apt upgrade и создаем юзера hadoop
- ssh-setup.sh: на пользователе hadoop edge-ноды генерируем ssh-ключ, переносим публичные/закрытые ключи и файл с разрешенными ключами на все ноды - получаем, что под пользователем hadoop можно перепрыгивать из любой ноды в любую
- install.sh - скачиваем на каждую ноду java и скачиваем на каждую ноду архив с дистрибутивом hadoop и распаковываем
- configure.sh - конфигурируем hdfs: настраиваем число реплик, путь к java и hadoop, порты для обращения к нейм-ноде
- run-hadoop.sh - конфигурируем нейм-ноду и разворачиваем hdfs

  Все сделать можно запустив выше перечисленные файлы в указанном порядке от лица пользователя team edge-ноды
