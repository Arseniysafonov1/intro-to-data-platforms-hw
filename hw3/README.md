# ДЗ-3. Инструкция

## 1. Установка и настройка PostgreSQL на 2-ю датаноду

- Скачиваем PostgreSQL.
- Меняем адрес чтения сигналов: в `postgresql.conf` переменную `listen_addresses` заменяем на `team-25-01`.
- Меняем права на подключение: в `pg_hba.conf` добавляем 4 адреса — для каждой из ВМ.
- Переходим в юзера `postgres` и открываем `psql`. Создаем БД, пользователя, выдаем ему права на БД и назначаем владельцем.

## 2. Установка и настройка Hive на Edge-ноде

- Качаем дистрибутив Hive версии 4.0.0.alpha2 с `archive.apache.org` и распаковываем.
- Создаем конфиг `hive-site.xml`. В него пишем:
  - Отключаем авторизацию.
  - Путь к данным, которыми управляет Hive.
  - Порт, который будет слушать Hive.
  - Задаем хост и драйвер подключения.
  - Задаем логин/пароль юзера, созданного ранее.
- Добавим переменные окружения для Hive и дополним `Path` путем к Hive.

## 3. Подготовка HDFS

- Создаем папку для Hive.
- Выдаем права на созданную папку и `tmp`.

## 4. Запуск

- Инициализируем хранилище.
- Запускаем `hiveserver`, `metastore`.
- Можно проверить корректность с помощью команды:

```bash
beeline -u jdbc:hive2://team-25-en:5433 -n scott -p tiger
```

Для автоматического развертывания достаточно запустить скрипты из `scripts` в порядке нумерования от лица `team@team-25-en`.
